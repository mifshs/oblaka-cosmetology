# Косметологический кабинет «Облака» (Ульяновск)

Официальный сайт косметологического кабинета эстетической и врачебной косметологии «Облака».

## О проекте
- **Стек**: HTML5, CSS3 (Bento Grid, CSS Variables), Vanilla JavaScript.
- **Шрифты**: Montserrat (заголовки и акценты) + Roboto (основной текст и интерфейс).
- **Стиль**: Тёплая велнес-эстетика (Solus style), адаптивный дизайн для мобильных устройств, планшетов и десктопов.
- **Функционал**:
  - Каталог услуг с фильтрацией по категориям (Лицо, Кожа век, Чистки, Пилинги, Пигментация).
  - Интерактивный прайс-лист с разбивкой по вкладкам.
  - Интерактивный аккордеон с ответами на частые вопросы.
  - Интерактивная форма записи на приём с автоподстановкой выбранной процедуры и валидацией.
  - Мобильное меню и плавающая кнопка быстрой записи на смартфонах.
  - Информация о лицензии, враче-дерматовенерологе и сертифицированной космецевтике (Holy Land, Christina, Gigi, Sesderma).
